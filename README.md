# Expense Tracker WEB APP
## how to Download 
first cloning this git in your directory (folder)
```bash 
git clone https://github.com/Raghurajpratapsingh28/Expense-Tracker.git
```
Then you have to install Node mmodules file from
```bash
npm install
```
Then Your file is Ready to Run ENTER
```bash
npm run dev
```
